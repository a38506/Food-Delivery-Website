Sử dụng Render.com để deploy
Render.com là một nền tảng cloud hosting hiện đại cho phép các nhà phát triển dễ dàng triển khai và quản lý ứng dụng, API, cơ sở dữ liệu, và các dịch vụ web khác. 
Render được thiết kế để đơn giản hóa quá trình triển khai, tiết kiệm thời gian và giảm bớt công việc quản trị máy chủ.
